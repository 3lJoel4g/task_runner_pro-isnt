# TC-021: Escalamiento SIGTERM → SIGKILL

## Requisitos cubiertos
RF-30.

## Procedimiento
1. Arranca daemon.
2. Envía `bash -c 'trap "" TERM; while true; do sleep 1; done'`
   (atrapa SIGTERM e ignora).
3. Verifica que está RUNNING.
4. `cancel 1` → debe enviar SIGTERM.
5. Espera 5 segundos.
6. `status 1` → debe estar CANCELED o FAILED con signal 9 (SIGKILL).
