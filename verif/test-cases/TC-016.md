# TC-016: Rechazo explícito con cola llena

## Requisitos cubiertos
RF-23, RF-25.

## Procedimiento
1. Arranca daemon con `max_workers=1`, `max_queue_size=2`.
2. Envía 3 jobs `sleep 600`: 1 RUNNING, 2 QUEUED.
3. `health` confirma `running=1 queued=2 max_queue_size=2`.
4. Envía un 4to job → debe responder `ERR queue full (max_queue_size=2,
   running=1, queued=2)`.
5. Cancela el RUNNING y espera 1.5s.
6. Envía otro job → debe ser aceptado (`OK id=`).

## Criterio de aceptación
`make test` deja `PASS` para TC-016.
