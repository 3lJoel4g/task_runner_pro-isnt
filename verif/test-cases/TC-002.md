# TC-002: Cola FIFO, límite de workers y cancelación

## Requisitos cubiertos
RF-01, RF-03, RF-04, RF-05, RF-06, RF-07, RF-08, RF-09, RF-10, RF-15, RF-17, RF-23, RF-25.

## Procedimiento
1. Arranca daemon con `max_workers=3`.
2. Envía `echo hola` y `bash -c 'exit 3'` para validar submit + exit code.
3. Envía 5 jobs `sleep 600`: los 3 primeros RUNNING, los 2 últimos QUEUED.
4. `health` confirma `running=3 queued=2`.
5. Cancela el primer QUEUED (dinámico) → `cancel requested (QUEUED)`.
6. Cancela el primer RUNNING (dinámico) → `cancel requested (RUNNING)`.
7. Comando inexistente no tumba el servicio.
8. `shutdown` limpio.
